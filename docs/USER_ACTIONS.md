# 你需要完成的事项

## 已确定

- 服务型个体经营者和实物销售商户都支持，先做通用基础版。
- 汇报版 `D:\云迹科技` 保留不动；商业化开发在 `D:\云迹科技-商业化`。

## 现在准备，不阻塞本地开发

1. 提供服务和商品各一个日常流程样例：如何建单、分次收款、退款、交付/出库。
2. 找 3–5 位愿意试用的经营者；确认是否先邀请免费试用再收费。
3. 说明已有云平台、域名、邮件服务、AI 服务和月度预算。不要把密码或密钥发进聊天或 Git。

## 云端试用前

1. 由你持有云平台和域名账户，完成实名和付款；根据用户地区选择部署区域。
2. 通过平台密钥设置或本机受保护环境配置提供凭据；开通必要的邮件发送服务。
3. 确定支持联系方式、响应时间、备份恢复目标；核对隐私说明和适用的上线要求。
4. 和试用者核对订单、收款、退款、库存、报表的口径，验收真实样例。

## 收费前

1. 确定单一初始套餐、价格、试用期限、退款及到期导出政策。
2. 确定收款主体和收款渠道，完成商户资质申请；由账户持有人同意服务协议。
3. 平台订阅费与经营者的客户回款分开记账，不能混进经营报表。
4. 实际试用和故障演练通过后再决定开放范围，不把本地测试通过当作生产验收。

## AI 与我分别负责什么

开发工作包括代码、数据库、权限、测试、部署配置、错误修复、文档和检查点。你负责账户所有权、实际付款、业务决策、真实试用与服务承诺。尚未获得账号或业务决定时，先完成不依赖它们的工作，并在断点中明确待办。
