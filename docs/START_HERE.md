# 云迹科技 · 从这里开始

当前交付是独立的商业化试用基础版，已具备真实账号、经营数据库、邮箱验证与密码找回的软件流程。真实云部署、SMTP 投递和商户试用仍需完成；这不等于已经上线收费运营。

## 1. 选择正确目录

- 年度汇报演示版：`D:\云迹科技`，继续使用原启动方式。
- 商业化开发版：`D:\云迹科技-商业化`，分支 `feat/commercial-pilot`。

只在商业化目录执行本文命令。两个版本的代码、数据、端口和启动器独立，不自动覆盖或合并汇报版。

## 2. 在本机启动

双击商业化目录中的 **启动商业化版.bat**，访问 `http://127.0.0.1:5174`；停止时使用 **停止商业化版.bat**。

也可在 Node.js 24、pnpm 11.25.0 环境运行：

```powershell
Set-Location 'D:\云迹科技-商业化'
pnpm install --frozen-lockfile
pnpm dev
```

首次进入点击「创建空间」，填写自己的邮箱、12–128 字符密码和空间名称。没有默认演示密码，新空间为空；已有数据库不会被启动流程重置。

本地未配置 SMTP 时，邮件验证和邮件找回不可用，页面明确提示；注册、登录和业务管理仍可使用，不会假称已发送邮件。经营记录保存在本目录 `.local/database` 的 PGlite 中，同一服务下登录同一账号可看到相同数据；复制代码到另一台电脑不会同步数据库。

## 3. 跑通第一笔业务

1. 新增客户。
2. 新建订单；服务或商品业务用分类区分。
3. 在订单「收退款」中登记实际收款；退款关联原收款，不直接改已收金额。
4. 商品录入期初库存，后续通过「出入库」记录数量与原因。
5. 查看经营概览、收支与统计，再向经营助手提问。

经营日期和周/月/年范围统一按北京时间。收支结余是现金流入减现金流出（包括退款），不是会计净利润。订单暂不自动扣库存，经营助手目前为服务器规则模式。

## 4. 使用邮箱验证与找回

配置邮件服务后：

- 登录后的空间设置显示邮箱验证状态，并提供「重新发送验证邮件」。
- 生产环境未验证账号先进入引导页；打开邮件链接并点击「确认验证邮箱」后，再进入工作台。其他已打开页面可点「我已验证，继续进入」。
- 登录页「忘记密码」受理注册邮箱的重置申请。打开重置链接，设置并确认新密码后重新登录；目标账号旧会话失效。
- 邮件链接令牌读取后即从地址栏移除，只在当前页面内存保留。刷新或离开后需重新打开完整邮件链接；打开链接本身不自动验证。

申请已受理不代表已送达。邮件队列在进程内，服务重启或投递失败后不保证自动补发；请在冷却期后重新申请并检查垃圾邮件。注册提示邮件暂未排队时，账号已经创建，无需重复注册。

生产必须配置完整 SMTP、HTTPS 来源、PostgreSQL 和邀请码，并强制邮箱验证；不能用关闭验证开关代替邮件配置。真实 SMTP、发信域名与实际邮件到达必须另行验收。配置见 [部署与维护手册](OPERATIONS.md)。

## 5. 验证与报告

```bash
pnpm check
pnpm test:recovery
pnpm test:e2e
pnpm test:auth:e2e
```

`check` 已包括账号恢复测试，单独命令适合针对性复查。浏览器默认在 Windows 使用 Edge；Linux 等环境先安装 Chromium：`pnpm exec playwright install --with-deps chromium`。

- 经营浏览器报告：`test-results/commercial/report.json`。
- 邮件恢复浏览器报告：`test-results/auth-recovery/report.json`。
- 同目录包含截图与 `trace.zip`；单测、API、安全和恢复测试输出到终端/CI。

测试使用临时数据库和内存 fakeMailer，不写入日常业务库、不向真实邮箱发信。当前本地最终集成已通过：业务 13、API 22、安全 8、恢复 19 项；经营浏览器 16 阶段、邮件浏览器 9 阶段，均无非预期控制台错误。原生 PostgreSQL 的 API、恢复及非空认证数据整库恢复也已验证。详细范围见 [项目 README](../README.md)，这些结果不代表远端 CI 或真实 SMTP 投递通过。

- 用于正式试用的云账号、域名和 HTTPS 地址。
- PostgreSQL 与备份存储资源。
- SMTP 服务、可用发件地址和发信域名管理权限。

密钥通过服务端环境或云平台密钥配置提供，不写入 Git、文档或浏览器。具体待办见 [用户行动清单](USER_ACTIONS.md)；上线前逐项完成 [发布验收](RELEASE_CHECKLIST.md)。
